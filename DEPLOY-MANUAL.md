# Инструкция: публикация grip-pro.ru

> Хостинг сайта: **GitHub Pages** (без VPS, без nginx, без certbot).
> SSL сайта включается в GitHub после DNS — отдельный сертификат не покупать.
> Почта: платная **Почта Рег.ру**, ящик `hi@grip-pro.ru`. Записи почты — рядом с GitHub, парковку и A сайта не путать.

---

## Часть 0. Домен в кабинете reg.ru

Частичное управление **уже есть** — эту часть пропусти.

Если домен вдруг пропал из списка: владелец передаёт снова (Операции → Передать в частичное управление), ты принимаешь оферту в Уведомлениях. Пароль от чужого кабинета не нужен.

## Часть 1. Репозиторий на GitHub

Репозиторий уже создан: https://github.com/taniksem2007-png/Grip  
Он **Public** — это нужно для бесплатного GitHub Pages.

### 1.1 Загрузить код (если агент ещё не запушил)

В папке проекта, PowerShell:

```powershell
git init
git add .
git commit -m "Initial commit: static site"
git branch -M main
git remote add origin https://github.com/taniksem2007-png/Grip.git
git push -u origin main
```

- Коммиты **на английском** (на Windows кириллица в `git log` ломается)
- Команды через `;`, не `&&`
- Вместо пароля при push — Personal Access Token: GitHub → Settings → Developer settings → Personal access tokens

### 1.2 Файл CNAME

В корне репозитория одна строка:

```
grip-pro.ru
```

Без `https://`, без `/`, без `www`.

## Часть 2. GitHub Pages

1. Открой https://github.com/taniksem2007-png/Grip/settings/pages
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `main` → **`/ (root)`** → **Save**
4. Подожди 1–2 мин — появится `https://taniksem2007-png.github.io/Grip/`
5. **Custom domain:** `grip-pro.ru` → **Save**
6. ⚠️ DNS check failed — нормально, пока нет записей на reg.ru. Домен не отменяй.

### HTTPS (после DNS)

1. Подожди **15–60 минут** после DNS сайта
2. Settings → Pages → **Check again**
3. Когда DNS подтверждён — **Enforce HTTPS**

Галочка HTTPS серая сразу — так и должно быть.

## Часть 3. DNS сайта на reg.ru

1. https://www.reg.ru/ → **Мои домены** → `grip-pro.ru`
2. **DNS-серверы и управление зоной**
3. DNS-серверы: **`ns1.reg.ru`** и **`ns2.reg.ru`**
   - Если `hosting.reg.ru` — смени на ns1/ns2.reg.ru (иначе эта инструкция не совпадёт с панелью хостинга)
4. **Ресурсные записи**
5. **Удали парковочные** A `@` на IP reg.ru / «домен не подключён»
6. Четыре **отдельные** A-записи:

| Тип | Subdomain | Значение |
|-----|-----------|----------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

7. CNAME для www:

| Тип | Subdomain | Значение |
|-----|-----------|----------|
| CNAME | www | taniksem2007-png.github.io |

В CNAME — **`taniksem2007-png.github.io`**, не `taniksem2007-png.github.io/Grip`. Логин — владелец репозитория.

8. Сохрани. Подожди **15–60 минут**.

По желанию четыре AAAA `@`: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.

## Часть 4. Почта Рег.ру

Услуга платная: https://www.reg.ru/hosting/mail → тариф → **Заказать**.

Сайт на GitHub не переезжает. DNS почты — **в ту же зону**. Четыре A GitHub для `@` **не удалять**.

Заказывай почту **в том кабинете, где входишь в панель «Хостинг Mail»** (обычно твой кабинет после частичного управления).

### 4.1 Почтовый домен

1. Кабинет → **Хостинг** → **Хостинг Mail** → **+ Добавить почтовый домен** (или Войти в панель → Почтовые домены → Создать)
2. Имя: `grip-pro.ru`
3. **IP** — скопируй с формы. Это IP для записи A `mail`. **Не выдумывай и не ставь его на `@`.**
4. Действие по умолчанию: **Игнорировать и удалить**
5. DKIM: вкл., селектор `dkim`, 2048
6. DMARC: вкл.
7. **Создать**
8. SSL для почты — включи после создания, если ещё выкл.

Если панель показала TXT DKIM и DMARC «добавьте вручную» — добавь в ресурсные записи (автоматом не появятся).

### 4.2 DNS почты

IP почты ниже — **только тот, что скопировали с формы** в шаге 4.1.

| Тип | Subdomain | Значение | Приоритет |
|-----|-----------|----------|-----------|
| MX | @ | mx1.hosting.reg.ru | 10 |
| MX | @ | mx2.hosting.reg.ru | 15 |
| A | mail | *IP с формы почтового домена* | |
| TXT | @ | `v=spf1 a mx include:_spf.hosting.reg.ru ip4:*IP-с-формы* ~all` | |
| TXT | dkim._domainkey | *вставить TXT из уведомления панели* | |
| TXT | _dmarc | *из уведомления* или `v=DMARC1; p=none; aspf=r; sp=none` | |

Ключ DKIM с другого домена не копировать.

### 4.3 Ящик

Хостинг Mail → Войти в панель → **Почта** → **Создать ящик**: `hi` + домен `grip-pro.ru` + пароль.

Вход: https://roundcube.hosting.reg.ru/ — полный адрес `hi@grip-pro.ru` и пароль.

Проверка: письмо с личной почты на `hi@grip-pro.ru` → ответ с ящика.

## Часть 5. Проверка

1. GitHub → Settings → Pages → **Check again** → **Enforce HTTPS**
2. Браузер: https://grip-pro.ru
3. Почта: входящее и исходящее на `hi@grip-pro.ru`

PowerShell:

```powershell
Invoke-WebRequest -Uri "https://grip-pro.ru" -Method Head -UseBasicParsing
nslookup grip-pro.ru 8.8.8.8
nslookup -type=MX grip-pro.ru 8.8.8.8
```

Ожидание: сайт **200**, A-записи GitHub (`185.199.108–111.153`), MX на `mx1`/`mx2.hosting.reg.ru`.

## Частые ошибки

| Симптом | Что делать |
|---------|------------|
| HTTPS нельзя включить | Подождать DNS, Check again — не покупать SSL и не ставить certbot |
| Страница reg.ru «домен не подключён» | Удалить парковочные A, добавить 4 A GitHub |
| `InvalidDNSError` в GitHub | Проверить 4 A + CNAME, ждать до 24 ч, Check again |
| Работает www, не работает без www | Все 4 A для `@` |
| Сайт открылся с VPN, дома нет | `nslookup grip-pro.ru 8.8.8.8` — если там GitHub, деплой ок, сменить DNS у провайдера |
| После почты сайт стал «не тот» / парковка | На `@` снова IP почты вместо GitHub — вернуть 4 A GitHub; IP почты только у `mail` |
| Письма в спаме | Нет SPF/DKIM в зоне — перенести TXT из уведомления панели |
| Думали, нужен Netlify / VPS | Для статики достаточно Pages |
| Кракозябры в git log | Коммиты на английском |
| Нет домена в кабинете | Часть 0: частичное управление, не общий пароль |
